## Architecture

- `shared/leaderboard.js`: the one rules module (382, time floors, names, handles, URL parsing), imported by game and API; `db/schema.sql` mirrors it as CHECKs.
- `api/scores.js` wires `api/_lib/{config,http,scores,store,notify}.js`: fail-closed config (prod DB only in Production), origin+JSON gate, per-IP 5/min then global 60/min limiter, insert+rank in one Neon HTTP transaction, Resend alert.
- `src/runClock.js` (pure, tested) + `src/run.js` (install, `beginRun`, `retryLevel`); `src/settings.js`, `src/audio.js`, `src/fx.js` (`shake`/`flash`/CRT); `src/menu.js`; scenes `Settings.js`, `Leaderboard.js`; `src/scoreForm.js` + `src/profile.js` + `src/api.js`.
- Build: `vite build` to `dist/`; Vercel adds the function. Tests: `node --test` (PGlite runs the real schema).

## Key decisions (do not relitigate)

- Neon, not Supabase: Supabase Free pauses after 7 idle days; Neon wakes on demand.
- Rank most stars, then time: Travis's call; Hydra skulls pay 0 so 382 is a real cap.
- Publish first, hide afterwards, email alert: Travis's call; anti-cheat is sanity checks only ("not super serious"); an offline eval/audit later.
- No run tickets: they cost complexity and bought ~61 s of forger wait.
- 15-min edge cache (`s-maxage=900, swr=86400`): keeps Neon under quota; the POST answer carries the fresh board.
- `sc_app` created in SQL with SELECT/INSERT only: console roles join `neon_superuser`.
- Level1 restart/death = new run: Level1 has no checkpoint; carrying the clock only punishes resets.
- Time floors from level geometry at ~60% (59.5 s): a full human run can't be automated here.
- Wall clock, not summed `rawDelta`: rawDelta misses focus-reset time and counts Firefox hidden frames.

## Dead ends (do not retry)

- HMAC start tickets (see above). `disableGlobalCapture()` for the form: any later `addKey` re-enables it; stopPropagation at the form root instead. Phaser `scale.startFullscreen()`: moves only the canvas, strands DOM overlays; use `documentElement.requestFullscreen`. Stamping a stopwatch in a separate tool call from the key press: read -3.4 s; stamp in-page. Chrome DevTools "new tab" never hides the page, so hidden-tab timing can't be automated there.
