## Architecture (what this session touched)

- `src/touch.js`: `TOUCH` flag, the DOM pad and rotate overlay, `touch` state (`takeJump`,
  `dropJump`, `reset`), `showPad`/`dimPad`, `enterFullscreen`. Player.tick ORs it with the keyboard.
- `src/scenes/HUD.js`: touch strip layout, taps (powers, talk, pause), `setPaused()`, auto-pause.
- `src/victorySong.js`: score, synth, 150 ms lookahead scheduler; `renderVictorySong()` for offline checks.
- `src/glyphs.js`: the font's glyph table, Phaser-free so `scripts/make-images.mjs` shares it.
- `public/`: favicons, `apple-touch-icon`, `icon-192/512`, `og.png`, `manifest.webmanifest`.

## Key decisions (do not relitigate)

- Touch buttons are DOM at the screen corners, not canvas: the letterboxed 16:9 canvas leaves bars,
  so corner buttons cover about half as much game on iPhones and almost none on tablets.
- Powers are tapped on the terminal bar, not extra buttons: the tutorial toasts already pulse those slots.
- Start and retry taps act on release, and only if they began on that screen: Android grants
  fullscreen only from a release, and a tap that left one screen must not start the next.
- End-screen taps are touch-only: a stray desktop click must not cut the win screen short.
- Billboard lettering is its own 3x-resolution layer (`bg_signs`) above the skyline haze, in the
  pixel font: Travis asked for readable signs; the far < mid < near ladder still holds for the skyline.
- License: Apache 2.0 (Travis, 2026-09-26): open and reusable with attribution; it does not stop resale.
- The "dario's office" sign stays: a public figure, Travis's call (2026-09-26).
- A pause dims the pad instead of hiding it: a resting thumb carries over like a held key; queued jumps are dropped.
- The victory song ships as MIDI note data on a synth routed through Phaser's mute node: no file,
  N mutes it; loudness set by measuring against the level music.
- Carried: no Phaser bloom; the far < mid < near opacity ladder is Travis's call; the 0.3 block
  wash; MAX carries into the boss; gaslight effects land even in god mode; voice fires on release.

## Dead ends (do not retry)

- `import('/src/voice.js')` from devtools after an HMR edit loads a second module instance (the
  game holds a `?t=`-stamped copy): no listeners, no events. Use `window.voice` and `window.game`.
- Carried: `body.setMaxVelocityY` as the fall cap (clamps the jump); lowering far/mid alpha (the sun
  brightens); `cam.postFX.clear()` (drops the CRT too); claude-in-chrome is not connected, use
  chrome-devtools, whose `evaluate_script` `filePath` must be inside the project.
