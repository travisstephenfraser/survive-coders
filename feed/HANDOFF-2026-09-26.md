## Architecture

- `src/main.js`: Phaser config (960x540, world zoom 3x onto 320x180), CRT pipeline.
- `src/scenes/PlayScene.js`: shared world, collisions, prompts and MAX stream, pickups, hazards,
  `markBlocks`. `Level1.js`, `BossHQ.js` (checkpoint incl. tokens), `HUD.js`, `Title.js`, `End.js`.
- `src/entities/`: `Player.js` (input, fire/stream), `enemies.js`, `Hydra.js`,
  `ContextOverflow.js` (rain and context rot). Touch input will OR into `Player.tick`.
- `src/fx.js` (CRT, `pop`), `sprites.js` / `backdrops.js` / `hqArt.js` (art drawn at boot),
  `voice.js`, `util.js` (`MAX_TOKENS` etc.). No build beyond Vite.

## Key decisions (do not relitigate)

- No Phaser bloom: its 50/50 blend halves the frame, and a lower strength is darker, not softer.
- The far < mid < near opacity ladder is Travis's call. The skyline recedes via haze because
  lowering far/mid alpha lets the sun show through.
- Gameplay readability comes from outlines, glow and the block wash. A 0.4 wash read as brick
  ("too Mario").
- Sprite brightness lifts are gone: they only compensated for the bloom.
- MAX is a token budget with a usage-limit gag, not a timer. Tokens carry into the boss and the
  checkpoint restores what you entered with, the same rule as stars.
- Gaslight: effects land on contact whenever the player is targetable; god mode and i-frames
  protect HP only.
- Overflow rain is white and gray: green means success in this game (refactor flash, ✓ ran).
- God mode is a secret; only the in-game badge shows it. Keep it out of the README.
- Voice fires on M release and 1/2/3 always work, so demo-room talk never triggers powers.
- One outcome per encounter; cutscenes freeze enemies and damage.
- History was rewritten and the repo recreated to purge the Sci-Fi Starter files and a personal
  email. Commits use the GitHub no-reply address.

## Dead ends (do not retry)

- `body.setMaxVelocityY` as the fall cap: it also clamps the jump (apex 44 px). Clamp only when falling.
- Lowering far/mid alpha to calm the skyline: the sun brightens behind them (skyline p99 97.7 → 113.4).
- `cam.postFX.clear()` to drop only bloom: it resets every post pipeline, CRT included.
- claude-in-chrome is not connected; use chrome-devtools. Its `evaluate_script` `filePath` must be
  in the project (`feed/shots/`); read frames via `game.renderer.snapshot`, not screenshots.
